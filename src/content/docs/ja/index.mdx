FractalTextは，人間が読め，機械が編集でき，行ごとに解釈可能で，再帰的な平文のシンプルなデータフォーマットです．

リスト，辞書，値のみから成ります．
全ての値は文字列です．データ交換フォーマットは型を要求すべきではありません．

FractalTextはデータフォーマットです．
- リストと辞書の2つのみを持ちます．
- コメントを挿入できます．
- リストの要素として文字列値のみが許可されます．
- 機械的に(構造やコメントを保存しながら)編集ができます．

以下の制約があります．
- 辞書はリストを含めますが，リストは辞書を含めません．
- リストの要素は改行を含むことができません．
- 辞書のキーは改行を含むことができません．

Example:
```txt
:key1
  value1-1
  value1-2

:key2
  :key2-1
    value2-1
    value2-2
  :key2-2
    ""
    value2-4

#comment1
```
