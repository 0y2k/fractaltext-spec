FractalText is a dead simple, human readable, machine editable, line-wise interpretable, recursive plaintext data format.

It contains only list, dict and value.
All values are string, since data exchange format should not require types.

FractalText is a data format. It:
- only have two parts; list and dictionary.
- can write some comments.
- includes only string value as a element of list.
- aims in-place editing easily.

Restrictions:
- dictionary may contain list, but list may not contain dictionary.
- list element must not contain a newline character.
- dictionary key must not contain a newline character.

Example:
```txt
:key1
  value1-1
  value1-2

:key2
  :key2-1
    value2-1
    value2-2
  :key2-2
    ""
    value2-4

#comment1
```
